# ui

## Running unit tests

Run `bun test` from the root of the repo to execute all unit tests.

## Running end-to-end tests locally

Run `yarn workspace @opencloning/tg-oss-ui launch-e2e` to launch the Cypress test runner locally

## Installation (react)

```
yarn add @opencloning/tg-oss-ui react react-dom
```

## Running locally

```
yarn workspace @opencloning/tg-oss-ui start
```
